개인정보처리방침

시행일: 2026년 10월 14일

1. 적용 대상

이 방침은 라이프큐브가 운영하는 짱툴 웹사이트(jjangtool.com)와, 운영자가 자신의 블로그·쓰레드 계정을 관리하려고 만든 짱툴 쓰레드 분석 앱(Meta Threads API 사용)에 적용됩니다.

2. 짱툴 웹사이트

짱툴의 계산기·변환 도구는 입력한 값을 이용자의 브라우저 안에서만 처리하며, 서버로 보내거나 저장하지 않습니다. 회원가입·로그인이 없고 개인정보를 수집하지 않습니다.

일부 도구는 기능에 필요한 외부 서비스(예: 내 아이피 확인의 ipify)를 부르며, 그 내용은 각 도구 페이지에 적혀 있습니다.

3. 짱툴 쓰레드 분석 앱

누가 쓰나요 — 운영자 본인과, 운영자가 앱의 테스터로 직접 등록한 운영자 소유 쓰레드 계정만 연결합니다. 다른 이용자의 계정을 연결하거나 대신 글을 올리지 않습니다.

받아 오는 정보

  • 연결한 운영자 계정의 아이디·프로필, 그 계정이 올린 글과 글별 지표(조회·좋아요·답글·리포스트·인용·공유), 계정 지표(팔로워 수, 링크 클릭 수) — threads_basic, threads_manage_insights, threads_read_replies
  • 키워드·주제 태그로 검색되는 공개 쓰레드 글의 본문·작성 시각·작성자 아이디·글 주소 — threads_keyword_search

쓰는 곳 — 운영자가 자신의 블로그와 쓰레드 글을 기획하려고, 어떤 주제·글 모양(첫 줄 유형, 길이, 태그, 광고 표시 위치 등)이 많이 읽히는지 통계로 봅니다. 개인을 추적하거나 프로필을 만들지 않고, 광고·판매·제3자 제공에 쓰지 않습니다.

저장 — 받은 정보는 운영자 개인 컴퓨터의 파일에만 저장되며 외부 서버에 올리거나 공유하지 않습니다. 접근 토큰은 운영자 컴퓨터에 권한을 제한한 파일로 보관합니다.

보관 기간 — 글 지표는 최근 30일분을 주기적으로 새로 받아 덮어씁니다. 검색 결과는 최근 검색 기록 위주로 보관하고 오래된 것은 지웁니다. 앱 연결을 끊으면 해당 계정의 정보와 토큰을 지웁니다.

게시 — 이 앱은 쓰레드에 글을 올리지 않습니다(게시 권한을 쓰지 않음).

4. 삭제 요청

자신의 공개 글이 검색 결과에 저장된 것을 지우고 싶다면 데이터 삭제 안내에 따라 요청해 주세요. 확인 후 지체 없이 지웁니다.
