넛으로 끝나는 단어 · 끝말잇기 공격 단어

끝말잇기에 쓸 수 있는 「넛」 단어를 모았습니다. 국립국어원 우리말샘 명사 기준이고, 두음법칙까지 반영했습니다. 단어를 누르면 뜻이 보입니다.

3개넛으로 시작하는 단어
7개넛으로 끝나는 단어
7개넛으로 끝나는 준한방 단어

상대가 넛으로 끝나는 단어를 냈다면 넛으로 시작하는 단어 3개로 이어 갈 수 있습니다.

이어 갈 단어가 3개뿐이라 넛으로 끝나는 단어로 공격하면 상대가 막히기 쉽습니다.

넛으로 시작하는 단어

3글자 1개

  • 넛손자누이의 손자.

4글자 이상 2개

  • 넛할머니아버지의 외숙모.
  • 넛할아버지아버지의 외숙.

넛으로 끝나는 단어

2글자 1개

  • 도넛밀가루를 반죽하여 고리 모양으로 만들어 기름에 튀긴 과자.

3글자 3개

  • 캐슈넛캐슈의 열매.
  • 토피넛설탕과 버터 따위를 끓여 만든 토피와 견과류를 섞은 음식.
  • 도우넛밀가루를 반죽하여 고리 모양으로 만들어 기름에 튀긴 과자.

4글자 이상 3개

  • 헤이즐넛개암나무의 열매.
  • 두부도넛두부를 넣어 만든 도넛.
  • 찹쌀도넛밀가루 대신 찹쌀로 만든 도넛.

넛으로 끝나는 준한방 단어

상대가 이을 단어가 1~3개뿐인 단어입니다.

  • 도넛밀가루를 반죽하여 고리 모양으로 만들어 기름에 튀긴 과자.
  • 도우넛밀가루를 반죽하여 고리 모양으로 만들어 기름에 튀긴 과자.
  • 캐슈넛캐슈의 열매.
  • 토피넛설탕과 버터 따위를 끓여 만든 토피와 견과류를 섞은 음식.
  • 두부도넛두부를 넣어 만든 도넛.
  • 찹쌀도넛밀가루 대신 찹쌀로 만든 도넛.
  • 헤이즐넛개암나무의 열매.

자주 묻는 질문

넛으로 시작하는 단어는 몇 개인가요?

우리말샘 기본 명사 기준 3개입니다.

넛으로 끝나는 단어는 몇 개인가요?

기본 명사 기준 7개이고, 그중 한방단어는 0개입니다.

끝말잇기에서 두음법칙을 써도 되나요?

보통 허용합니다. 예를 들어 「력」으로 끝나면 「역」으로, 「리」로 끝나면 「이」로 시작하는 단어를 이어도 됩니다. 시작 전에 규칙을 정해 두세요.

어떤 사전 기준인가요?

국립국어원 우리말샘의 명사(일반어) 기준입니다. 옛말·방언·북한어·고유명사(지명·인명)는 뺐습니다.
