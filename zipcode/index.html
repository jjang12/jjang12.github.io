우편번호 찾기 · 영문주소 변환

도로명, 지번, 건물명으로 검색해 주소를 고르면 우편번호와 영문주소가 바로 나옵니다. 동·호수를 넣으면 해외직구·영문 서류에 쓸 영어 주소를 만들어 줍니다.

예: 테헤란로 152, 판교역로 235, 반포동 20-43, 롯데월드타워. 검색창은 카카오(다음) 우편번호 서비스입니다.

우편번호 (새 우편번호 5자리)

상세 주소 → 영문주소 만들기

영문주소 (한 줄)

해외직구·영문 서류 입력 칸

해외 쇼핑몰은 보통 Address Line 1에 번지·도로, Line 2에 동·호수를 넣습니다. 칸 이름 옆 값을 눌러 하나씩 복사하세요.

영문주소 쓰는 법

영문주소는 한글 주소와 순서가 반대입니다. 작은 단위(호수 → 동 → 건물 번호 → 도로명)부터 쓰고 마지막에 시·도, 나라, 우편번호를 붙입니다.

예) 서울특별시 강남구 테헤란로 152, 101동 1203호 → 101-1203, 152 Teheran-ro, Gangnam-gu, Seoul, Republic of Korea 06236

도로명은 「-ro(로)」, 「-gil(길)」, 「-daero(대로)」로, 구·군은 「-gu」, 「-gun」으로 씁니다. 아파트 동·호수는 「101-1203」처럼 줄여 쓰거나 「Apt 101-1203」으로 씁니다.

자주 묻는 질문

우편번호는 몇 자리인가요?

2015년 8월부터 5자리 새 우편번호(국가기초구역번호)를 씁니다. 예전 6자리(123-456) 우편번호는 더 이상 쓰지 않습니다.

영문주소는 어디 기준인가요?

행정안전부 도로명주소의 공식 영문 표기를 그대로 보여 줍니다(카카오 우편번호 서비스 제공). 해외직구, 여권·비자 서류, 해외 송금에 그대로 쓸 수 있습니다.

해외직구 주소에 동·호수는 어디에 쓰나요?

Address Line 2(Apartment, suite 등)에 「101-1203」처럼 넣으면 됩니다. 칸이 하나뿐이면 맨 앞에 붙여 「101-1203, 152 Teheran-ro …」처럼 씁니다.

State / Province 칸에는 뭘 쓰나요?

시·도 이름을 씁니다. 서울은 Seoul, 경기도는 Gyeonggi-do, 부산은 Busan처럼 씁니다. City 칸에는 시·군·구를 씁니다.
